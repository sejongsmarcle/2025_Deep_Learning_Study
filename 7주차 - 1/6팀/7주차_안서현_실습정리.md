- 문제 정의: '5개 보기 중 틀린 것 찾기'를 '각 문장이 문법적으로 옳은지/틀린지'를 판단하는 이진 분류(Binary Classification) 문제로 변환합니다.

- 데이터 준비: 수능 및 모의평가 기출문제에서 문장을 추출하여 '정답(True)'과 '오답(False)' 레이블을 붙여 데이터를 만듭니다.

- 기본 모델 (Baseline): LSTM을 이용한 기본 모델을 만들어 성능을 측정합니다.

- 성능 향상 ① (Transfer Learning): 더 큰 외부 데이터셋(CoLA)으로 모델을 **미리 학습(Pre-training)**시킨 후, 수능 데이터로 **미세 조정(Fine-tuning)**하여 성능을 높입니다.

- 성능 향상 ② (심화 모델): LSTM의 모든 시점(timestep) 정보를 활용하는 Max Pooling 기법을 적용한 모델을 만들어 성능을 극대화합니다.

- 데모 및 최종 평가: 완성된 모델들로 실제 수능 문제를 풀어보며 성능을 비교하고 검증합니다.

PART 2. 기본 LSTM 모델 구현 (p.259 ~ p.273)

1. 모델 아키텍처 (LSTMClassifier)

- 입력: 문장을 토큰화하고 숫자로 변환한 시퀀스.

- 구조:

Embedding Layer: 단어 토큰을 고차원 벡터로 변환.

Bidirectional LSTM Layer: 문장의 양방향 문맥을 학습. 이 모델에서는 마지막 시점의 출력값만 사용.

Fully Connected Layer: LSTM의 최종 결과를 받아 0과 1 사이의 확률값으로 변환.

Sigmoid Activation: 최종 출력값을 확률로 만듦.

- 최종 출력: 문장이 문법적으로 맞을 확률 (Logit 1개).

<pre>
 class LSTMClassifier(nn.Module):
    def __init__(self, num_embeddings, embedding_dim, hidden_size, num_layers, pad_idx):
        super().__init__()
        self.embed_layer = nn.Embedding(
            num_embeddings=num_embeddings,
            embedding_dim=embedding_dim,
            padding_idx=pad_idx
        )
        self.lstm_layer = nn.LSTM(
            input_size=embedding_dim,
            hidden_size=hidden_size,
            num_layers=num_layers,
            bidirectional=True,
            dropout=0.5,
            batch_first=True
        )
        self.last_layer = nn.Sequential(
            nn.Linear(hidden_size * 2, hidden_size), # 양방향이므로 *2
            nn.Dropout(0.5),
            nn.LeakyReLU(),
            nn.Linear(hidden_size, 1)
        )
        self.sigmoid = nn.Sigmoid()

    def forward(self, x):
        embed_x = self.embed_layer(x)
        output, (hidden, cell) = self.lstm_layer(embed_x)
        # 마지막 시점의 결과만 사용
        last_output = output[:, -1, :]
        logits = self.last_layer(last_output)
        # squeeze(1)로 불필요한 차원 제거
        probs = self.sigmoid(logits.squeeze(1)) 
        return probs
</pre>

3. 학습 및 평가

- 손실 함수: BCELoss (이진 교차 엔트로피)

- 옵티마이저: Adam

- 평가 지표: AUROC

- 정확도(Accuracy)는 확률 임계값(Threshold)에 따라 쉽게 변동되므로 신뢰하기 어려움.

- AUROC는 모든 임계값에 대한 모델의 성능을 종합적으로 나타내므로 더 안정적인 지표.

PART 3. 성능 향상 전략 (p.274 ~ p.285)

1. 추가 데이터 활용 (Transfer Learning)

- 문제점: 수능 기출 데이터의 양이 너무 적어 모델이 충분히 학습하기 어려움.

- 해결책: 대규모 공개 데이터셋으로 먼저 영어 문법 지식을 학습시킨 후, 수능 데이터로 전문화.

- 추가 데이터셋: CoLA (Corpus of Linguistically Acceptability)

- 문장의 문법적 허용 여부를 판단하는 데이터셋 (우리 문제와 유사).

- 수능 데이터보다 훨씬 양이 많음 (약 10:1 비율).

- 학습 과정:

사전 학습 (Pre-training): CoLA 데이터로 기본 LSTM 모델을 학습. (단어 사전도 CoLA 기준으로 생성)

미세 조정 (Fine-tuning): 사전 학습된 모델을 가져와 수능 데이터로 추가 학습.

- 결과: AUROC 0.65385. 성능이 의미 있게 향상됨.

2. 심화 모델 (LSTM with Max Pooling)

- 문제점: 기본 모델은 LSTM의 마지막 정보만 사용하므로 문장 중간의 중요한 정보를 놓칠 수 있음.

- 해결책: LSTM의 모든 시점(단어)별 출력 결과를 모두 활용.

- 심화 모델 아키텍처 (LSTMPoolingClassifier):

Embedding Layer -> Bidirectional LSTM Layer (여기까지 동일)

(핵심) Max Pooling Layer: LSTM의 모든 시점 출력 벡터들 중에서 각 차원별로 가장 중요한(큰) 값만 추출. 이를 통해 문장 길이에 상관없이 고정된 크기의 핵심 정보 벡터를 얻음.

Fully Connected Layer -> Sigmoid Activation

- 학습 과정: 이 심화 모델에도 동일하게 CoLA 데이터로 사전 학습 후 수능 데이터로 미세 조정.

- 결과: AUROC 0.92308. 성능이 대폭 향상되어 매우 우수한 모델이 됨.

<pre>
 class LSTMPoolingClassifier(nn.Module):
    def __init__(self, num_embeddings, embedding_dim, hidden_size, num_layers, pad_idx):
        super().__init__()
        # Embedding, LSTM 레이어는 이전 모델과 동일
        self.embed_layer = nn.Embedding(...)
        self.lstm_layer = nn.LSTM(...)
        self.last_layer = nn.Sequential(...)
        self.sigmoid = nn.Sigmoid()

    def forward(self, x):
        embed_x = self.embed_layer(x)
        output, _ = self.lstm_layer(embed_x)
        
        # Max Pooling 적용을 위해 차원 변경
        output = output.permute(0, 2, 1)
        # 각 문장의 단어 벡터들 중 가장 중요한 특징을 추출
        pooled_output = torch.max(output, dim=2)[0]
        
        logits = self.last_layer(pooled_output)
        probs = self.sigmoid(logits.squeeze(1))
        return probs
</pre>

 # OOV(Out-of-Vocabulary) 오류를 방지하는 문제 풀이 함수
def predict_problem(model_path, problem_sentences):
    try:
        with open(model_path, "rb") as f:
            model_data = dill.load(f)
    except FileNotFoundError:
        print(f"'{model_path}' 파일을 찾을 수 없습니다. 모델을 먼저 학습하고 저장해주세요.")
        return None, None

    TEXT_field = model_data["TEXT"]
    classifier = model_data["classifier"].to(device)
    classifier.eval()

    scores = []
    # 사전에 없는 단어는 <unk> 토큰으로 처리
    unk_token_idx = TEXT_field.vocab.stoi[TEXT_field.unk_token]

    with torch.no_grad():
        for sentence in problem_sentences:
            tokens = [token.lower() for token in word_tokenize(sentence)]
            token_indices = [TEXT_field.vocab.stoi.get(token, unk_token_idx) for token in tokens]
            tensor = torch.LongTensor(token_indices).unsqueeze(0).to(device)
            prediction = classifier(tensor).item()
            scores.append(prediction)

    wrong_sentence_idx = np.argmin(scores)
    return wrong_sentence_idx + 1, scores
