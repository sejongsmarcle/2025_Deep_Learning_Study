1. Convolutional Neural Network (CNN)
   
   - 정의: Convolutional Neural Network(CNN)는 이미지나 영상을 다루는 컴퓨터 비전(Computer Vision)에서 가장 대표적으로 사용되는 인공신경망이다. 이미지 처리와 패턴 인식에 탁월한 성능을 보여주며, 딥러닝의 발전 영역에서 가장 두각을 나타내는 분야 중 하나이다.
     
   - 역사: 1980년대 얀 르쿤(Yann LeCun)이 개발한 LeNet 모델에서 처음 소개되었으나, 당시에는 긴 학습 시간 등의 한계로 널리 사용되지 못했다. 약 30년 후 과적합과 학습 시간 문제가 해결되면서 널리 사용되기 시작했다.
  
   - 활용: 현재는 이미지 분류는 물론, 얼굴 인식이나 자율 주행과 같은 고도의 객체 인식(Object Recognition) 분야에서도 핵심적인 기술로 사용되고 있다.
  
2. 이미지 데이터의 특징과 기존 신경망의 한계
   
   - 이미지란?: 사람의 눈에는 한 장의 사진처럼 보이지만, 컴퓨터는 이미지를 픽셀(Pixel) 단위의 숫자 행렬로 인식한다. 각 픽셀은 색상 정보를 담고 있으며(예: RGB 값), 이 픽셀들이 모여 격자 형태의 데이터를 이룬다.
  
   - 공간적 정보 (Spatial Feature): 이미지 데이터의 가장 중요한 특징은 공간적 정보이다. 특정 픽셀 주변에는 비슷한 색상과 형태의 픽셀이 위치할 가능성이 높으며, 이처럼 픽셀 간의 위치 관계는 이미지의 중요한 정보를 담고 있다.
  
   - 기존 신경망(다층 퍼셉트론, MLP)의 한계: 다층 퍼셉트론과 같은 전통적인 신경망은 1차원 벡터 형태의 정형 데이터(고정된 열과 행으로 구성된 데이터)를 입력으로 받는다. 따라서 2차원 행렬인 이미지를 입력하려면, 이를 1차원 벡터로 펼쳐야 한다(Flattening). 이 과정에서 픽셀 간의 중요한 공간적 정보가 손실되는 심각한 단점이 발생한다.
  
   - CNN의 해결책: CNN은 이미지를 2차원 또는 3차원 형태 그대로 입력받아, 공간적 정보를 보존하면서 학습할 수 있도록 설계되어 이러한 한계를 극복한다.
     
3. 합성곱 층 (Convolutional Layer)

   - 핵심 역할: CNN의 가장 핵심적인 부분으로, 이미지의 공간적, 지역적 특징(Region Feature)을 추출하는 역할을 한다.
구성 요소: 합성곱 층은 입력 이미지와 작은 크기의 필터(Filter, 또는 커널 Kernel) 간의 합성곱(Convolution) 연산을 통해 새로운 **특성 맵(Feature Map)**을 생성한다.

   - 필터(Filter)의 역할 : 필터는 학습해야 할 **가중치(Weight)**이다. 초기에는 임의의 값으로 설정되었다가, 손실 함수가 줄어드는 방향으로 학습되면서 특정 패턴(예: 수직선, 수평선, 곡선, 특정 색상 조합 등)을 감지하도록 최적화된다.
  
   - 다양한 특징을 추출하기 위해 하나의 합성곱 층에서 여러 개의 필터를 사용하며, 각 필터는 서로 다른 특징을 추출한 특성 맵을 만들어낸다.
  
   - 하이퍼파라미터:
     
   - 필터 크기 (Filter Size): 필터의 높이와 너비. 필터 사이즈가 작으면 더 세밀한 특징을 포착할 수 있지만 연산량이 늘어난다.
  
   - 스트라이드 (Stride): 필터가 이미지 위를 이동하는 간격(보폭). Stride가 클수록 출력되는 특성 맵의 크기는 작아진다. (주로 1로 설정)
  
   - 패딩 (Padding): 합성곱 연산 시 이미지 크기가 줄어드는 것과 가장자리 정보가 소실되는 것을 방지하기 위해 입력 이미지 외곽에 특정 값(주로 0)을 채우는 기술이다. 패딩을 통해 입력과 출력의 크기를 동일하게 유지할 수 있다.
  
4. 합성곱 연산 (Convolution Operation)

   - 연산 과정: 필터가 이미지의 특정 영역(이를 수용 영역, Receptive Field라고 함) 위를 슬라이딩하면서, 겹치는 부분의 각 원소(픽셀 값)를 곱한 후 모두 더하여 하나의 값을 계산한다. 이 과정을 이미지 전체에 대해 반복하여 새로운 행렬인 특성 맵을 생성한다.
  
   - 특성 맵의 의미: 특성 맵의 각 값은 해당 위치에서 필터가 감지하려는 특징이 얼마나 강하게 나타나는지를 의미한다. 즉, 이미지의 지역적 특성을 분석한 결과이다. 층이 깊어질수록 이전 층에서 추출된 단순한 특징들을 조합하여 더 복잡하고 추상적인 특징(예: 눈, 코, 자동차 바퀴 등)을 감지하게 된다.
  
   - 활성화 함수 (Activation Function): 합성곱 연산이 끝난 후, 특성 맵에 ReLU와 같은 활성화 함수를 적용하여 비선형성을 추가한다. 이를 통해 모델이 더 복잡한 패턴을 학습할 수 있게 된다.
  
5. 풀링 층 (Pooling Layer)

   - 역할: 합성곱 층을 통해 얻은 특성 맵(Feature Map)의 크기(차원)를 줄여 연산량을 감소시키고, 주요 특징을 강조하는 역할을 한다.
  
   - 동작 방식: 학습할 가중치는 없으며, 지정된 영역 내에서 특정 값만 추출하는 단순한 연산을 수행한다.
  
   - 최대 풀링 (Max Pooling): 지정된 영역에서 가장 큰 값을 선택한다. 특징을 더욱 두드러지게 만드는 효과가 있다.
  
   - 평균 풀링 (Average Pooling): 지정된 영역의 값들의 평균을 취한다.
  
   - 특징: 풀링 층은 계산 비용을 줄이면서도 중요한 특징은 보존할 수 있게 해주며, 모든 합성곱 층 뒤에 항상 위치해야 하는 것은 아니고 선택적으로 사용된다.
  
6. 완전 연결 계층 (Fully Connected Layer, 밀집 층)

   - 역할: 추출된 모든 특징들을 종합하여 이미지를 최종적으로 분류(Classification)하거나 특정 값을 예측(Regression)하는 역할을 한다.
  
   - 플래튼 층 (Flatten Layer): 완전 연결 계층에 입력하기 위해, 이전 층들에서 나온 다차원의 특성 맵들을 1차원 벡터로 길게 펼쳐준다. (예: 32개의 8x8 특성 맵 → 32 * 8 * 8 = 2,048 크기의 벡터)
     
   - 완전 연결: Flatten을 통해 얻은 1차원 벡터를 입력으로 받아, 다층 퍼셉트론(MLP)과 동일한 구조로 최종 출력값을 계산한다. 출력층의 노드 수는 분류할 클래스의 개수나 예측할 값의 개수와 동일하게 설정된다.

   - 주의사항: 완전 연결 계층은 합성곱 층에 비해 학습할 가중치의 수가 훨씬 많다. 따라서 이 층을 너무 많이 쌓으면 과적합(Overfitting)을 유발하거나 학습 속도를 저하시키는 원인이 될 수 있다.
