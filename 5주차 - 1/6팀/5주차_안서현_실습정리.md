1. 프로젝트 소개
 
  - 목표 : 작물 잎 사진의 종류와 질병 유무를 분류하기
  
  - 데이터 수 : 약 40,000개 (코드 상 33개 클래스)

  - 데이터 구조: 각 폴더는 클래스 명(예: 'Tomato___Bacterial_spot')으로 저장되어 있으며, 해당 폴더마다 들어있는 사진들은 그 폴더의 클래스에 포함됩니다. 이 구조를 활용해 데이터를 불러옵니다.

2. 데이터 분할

데이터 분할은 전체 데이터셋을 모델 학습(train), 검증(validation), 그리고 최종 평가(test)를 위한 세 부분으로 나누는 과정입니다. 여기서는 6:2:2 비율로 데이터를 분할합니다.

먼저, 분할된 데이터를 저장할 `splitted` 폴더와 그 하위에 `train`, `val`, `test` 폴더를 생성합니다. 또한, 각 폴더 내부에 원본 데이터셋의 모든 클래스명으로 하위 폴더를 미리 만들어줍니다.

<pre>
import os
import shutil
 
# 원본 데이터셋이 위치한 경로를 지정합니다.
original_dataset_dir = './dataset'

# os.listdir() 메서드는 해당 경로 하위에 있는 모든 폴더의 목록을 가져오는 메서드입니다. 
# 이 경우 폴더 목록은 클래스의 목록에 해당하므로 이것을 classes_list로 저장합니다.
classes_list = os.listdir(original_dataset_dir)

# 나눈 데이터를 저장할 폴더를 생성합니다.
base_dir = './splitted'
os.mkdir(base_dir)

# 분리 후에 각 데이터를 저장할 하위 폴더 train, val, test를 생성합니다.
train_dir = os.path.join(base_dir, 'train')
os.mkdir(train_dir)
validation_dir = os.path.join(base_dir, 'val')
os.mkdir(validation_dir)
test_dir = os.path.join(base_dir, 'test')
os.mkdir(test_dir)

# train, validation, test 폴더 하위에 각각 클래스 목록 폴더를 생성합니다.
for clss in classes_list:
    os.mkdir(os.path.join(train_dir, clss))
    os.mkdir(os.path.join(validation_dir, clss))
    os.mkdir(os.path.join(test_dir, clss))
</pre>

다음으로, 각 클래스 폴더를 순회하며 이미지 파일 목록을 가져온 뒤, 6:2:2 비율로 분할하여 위에서 생성한 `train`, `val`, `test` 폴더에 각각 복사합니다.

**※참고**: 제공된 원본 코드(leaf.ipynb)의 두 번째 셀에는 모든 클래스에 대해 분할을 수행하지 않고 마지막 클래스에 대해서만 분할을 수행하는 로직 오류가 있습니다. 이로 인해 `ImageFolder`가 비어있는 클래스 폴더를 발견하고 `FileNotFoundError`를 발생시킵니다. 아래 코드는 이 오류를 수정한 버전입니다.

<pre>
import math

# for 문을 통해 모든 클래스에 대한 작업을 반복합니다.
for clss in classes_list:
    path = os.path.join(original_dataset_dir, clss)
    # path 위치에 존재하는 모든 이미지 파일의 목록을 변수 fnames에 저장합니다.
    fnames = os.listdir(path)

    # Train, Validation, Test 데이터의 비율을 지정합니다. 이 프로젝트에서는 6:2:2의 비율을 지정합니다.
    train_size = math.floor(len(fnames) * 0.6)
    validation_size = math.floor(len(fnames) * 0.2)
    test_size = math.floor(len(fnames) * 0.2)

    # Train 데이터에 해당하는 파일의 이름을 train_fnames에 저장합니다.
    train_fnames = fnames[:train_size]
    print('Train size(', clss, '):', len(train_fnames))
    # 모든 Train 데이터에 대해 for 문의 내용을 반복합니다.
    for fname in train_fnames:
        # 복사할 원본 파일의 경로를 지정합니다.
        src = os.path.join(path, fname)
        # 복사한 후 저장할 파일의 경로를 지정합니다.
        dst = os.path.join(os.path.join(train_dir, clss), fname)
        # src의 경로에 해당하는 파일을 dst의 경로에 저장합니다.
        shutil.copyfile(src, dst)

    # Validation 데이터에 해당하는 파일의 이름을 validation_fnames에 저장합니다.
    validation_fnames = fnames[train_size:(validation_size + train_size)]
    print('Validation size(', clss, '):', len(validation_fnames))
    for fname in validation_fnames:
        src = os.path.join(path, fname)
        dst = os.path.join(os.path.join(validation_dir, clss), fname)
        shutil.copyfile(src, dst)

    # Test 데이터에 해당하는 파일의 이름을 test_fnames에 저장합니다.
    test_fnames = fnames[(train_size + validation_size):
                         (validation_size + train_size + test_size)]
    print('Test size(', clss, '):', len(test_fnames))
    for fname in test_fnames:
        src = os.path.join(path, fname)
        dst = os.path.join(os.path.join(test_dir, clss), fname)
        shutil.copyfile(src, dst)
</pre>

3. 데이터 로드 및 전처리

분할된 데이터를 모델에 입력하기 위해 `torchvision`의 `ImageFolder`와 `DataLoader`를 사용합니다. `ImageFolder`는 폴더 구조를 기반으로 데이터셋을 생성하며, `transforms`를 통해 이미지 크기 조정, 텐서 변환, 정규화 등 다양한 전처리를 적용합니다.

<pre>
import torch
import torchvision.transforms as transforms
from torchvision.datasets import ImageFolder
from torch.utils.data import DataLoader

# 연산 장치 설정
USE_CUDA = torch.cuda.is_available()
DEVICE = torch.device("cuda" if USE_CUDA else "cpu")
BATCH_SIZE = 256
EPOCH = 30

# 이미지를 64x64로 변환 후 텐서로 변환하는 기본 전처리
transform_base = transforms.Compose([transforms.Resize((64,64)), transforms.ToTensor()])

# 훈련, 검증 데이터셋 로드
# (위의 데이터 분할 코드가 올바르게 실행되었다면 이 부분에서 오류가 발생하지 않습니다.)
train_dataset = ImageFolder(root='./splitted/train', transform=transform_base) 
val_dataset = ImageFolder(root='./splitted/val', transform=transform_base)

# 배치 단위로 데이터를 공급하는 데이터로더 준비
train_loader = torch.utils.data.DataLoader(train_dataset, batch_size=BATCH_SIZE, shuffle=True, num_workers=4)
val_loader = torch.utils.data.DataLoader(val_dataset, batch_size=BATCH_SIZE, shuffle=True, num_workers=4)
</pre>

4. 모델링

이 프로젝트에서는 두 가지 모델을 사용하여 성능을 비교합니다.

- **Baseline 모델**: 직접 정의한 간단한 CNN(Convolutional Neural Network) 모델입니다.
- **ResNet-50 모델**: ImageNet 데이터로 사전 학습된 ResNet-50 모델을 가져와 전이 학습(Transfer Learning)을 적용합니다.

<pre>
import torch.nn as nn
import torch.nn.functional as F
from torchvision import models

# --- Baseline 모델 정의 ---
class Net(nn.Module): 
    def __init__(self): 
        super(Net, self).__init__() 
        self.conv1 = nn.Conv2d(3, 32, 3, padding=1) 
        self.pool = nn.MaxPool2d(2,2)  
        self.conv2 = nn.Conv2d(32, 64, 3, padding=1)  
        self.conv3 = nn.Conv2d(64, 64, 3, padding=1)  
        self.fc1 = nn.Linear(4096, 512) 
        self.fc2 = nn.Linear(512, 33) # 클래스 개수 33개
    
    def forward(self, x):  
        x = self.pool(F.relu(self.conv1(x)))
        x = F.dropout(x, p=0.25, training=self.training)
        x = self.pool(F.relu(self.conv2(x)))
        x = F.dropout(x, p=0.25, training=self.training)
        x = self.pool(F.relu(self.conv3(x)))
        x = F.dropout(x, p=0.25, training=self.training)
        x = x.view(-1, 4096)  
        x = F.relu(self.fc1(x))
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.fc2(x) 
        return F.log_softmax(x, dim=1)  

# --- 전이 학습을 위한 ResNet-50 모델 준비 ---
resnet = models.resnet50(pretrained=True)  # 사전 학습된 모델 로드
num_ftrs = resnet.fc.in_features          # 마지막 FC 레이어의 입력 특징 수
resnet.fc = nn.Linear(num_ftrs, 33)       # 새로운 데이터셋의 클래스 수(33)에 맞게 FC 레이어 교체
resnet = resnet.to(DEVICE)

# ResNet의 초기 레이어들은 학습되지 않도록 가중치를 동결(Freeze)
ct = 0 
for child in resnet.children():  
    ct += 1  
    if ct < 6: 
        for param in child.parameters():
            param.requires_grad = False
</pre>
