1. 순환 신경망(RNN)
   
  - RNN : Recurrent Neural Network, 시간적으로 연속성이 있는 데이터를 처리하려고 고안된 인공 신경망

■ Recurrent? : ‘반복되는’의 뜻을 가진 단어, 이전 은닉층이 현재 은닉층의 입력이 되면서 반복되는 순환 구조를 의미한다.

■ 차이점 : 기억

● 기억? : 현재까지의 입력 데이터를 요약한 정보이다. 새로운 입력마다 기억은 수정된다.

■ RNN의 입력과 출력

● 일대일 : 시간의 흐름, 즉 순환이 없어 RNN이라고 말하기 어렵다. (예시 : 이미지 분류)

● 일대다: 입력이 하나이고, 출력이 다수인 구조이다. (예시 : 이미지 캡션)

● 다대일: 입력이 다수이고 출력이 하나인 구조이다. (예시 : 감성 분석기)

● 다대다: 입력과 출력 모두 다수인 구조이다. (예시 : 자동 번역기)

● 동기화 다대다: 입력과 출력 모두 다수인 구조이다. (예시 : 프레임 수준의 비디오 분류)

  - RNN 계층과 셀

■ 셀은 계층의 구성요소

● RNN 계층은 RNN 셀을 여러 번 반복해서 구성된 구조이다

■ 셀의 유형

● nn.RNNCell : SimpleRNN 계층에 대응되는 RNN 셀

● nn.RNNCell : GRU 계층에 대응 되는 GRU 셀

● nn.RNNCell : LSTM 계층 에 대응 되는 LSTM 셀.
