[ 1. 개요 ]

본 보고서는 Numpy 라이브러리를 사용하여 직접 구현된 간단한 순환 신경망(RNN) 코드에 대한 상세 분석을 제공합니다.

코드는 '훈민정음 언해본' 서문 텍스트를 학습 데이터로 사용하여 단어 시퀀스의 패턴을 학습합니다.

학습 완료 후, 사용자가 시작 단어를 입력하면 모델이 다음 단어들을 예측하여 새로운 문장을 생성하는 것을 목표로 합니다.

def data_preprocessing(data):
    data = re.sub('[^가-힣]', ' ', data) # 한글 이외 문자 제거
    tokens = data.split() # 공백 기준 분리
    vocab = list(set(tokens))
    vocab_size = len(vocab)

    word_to_ix = {word: i for i, word in enumerate(vocab)} # 문자, 인덱스 매핑
    ix_to_word = {i: word for i, word in enumerate(vocab)} # 인덱스, 문자 매핑

    return tokens, vocab_size, word_to_ix, ix_to_word
</pre>

설명:

이 함수는 원본 텍스트 데이터를 신경망이 처리할 수 있는 숫자 형태로 변환합니다.

1. 한글을 제외한 모든 문자를 공백으로 치환하여 데이터를 정제합니다.

2. 텍스트를 공백 기준으로 단어 리스트(토큰)로 분리합니다.

3. 고유한 단어의 집합인 어휘집(vocabulary)을 만들고 그 크기(vocab_size)를 계산합니다.

4. 각 고유 단어와 정수 인덱스를 서로 변환할 수 있는 딕셔너리 2개(word_to_ix, ix_to_word)를 생성하여 반환합니다.

3. 가중치 초기화 함수
--------------------------------------------------
<pre>
def init_weights(h_size, vocab_size):
    U = np.random.randn(h_size, vocab_size) * 0.01
    W = np.random.randn(h_size, h_size) * 0.01
    V = np.random.randn(vocab_size, h_size) * 0.01
    return U,W,V
</pre>

설명:

RNN 모델이 학습 과정에서 최적화할 3개의 파라미터(가중치 행렬)를 생성하고 초기화합니다.

- U: 입력층 -> 은닉층 가중치

- W: 이전 은닉층 -> 현재 은닉층 가중치 (RNN의 핵심 메모리 역할)

- V: 은닉층 -> 출력층 가중치

가중치는 작은 임의의 수로 초기화하여 학습이 안정적으로 시작되도록 합니다.

<pre>
def feedforward(inputs, targets, hprev):
    loss = 0
    xs, hs, ps, ys = {}, {}, {}, {}
    hs[-1] = np.copy(hprev) # 직전 시점의 히든 스테이트
    for i in range(seq_len):
        xs[i] = np.zeros((vocab_size, 1))
        xs[i][inputs[i]] = 1  # 각각의 word에 대한 one hot coding
        hs[i] = np.tanh(np.dot(U, xs[i]) + np.dot(W, hs[i - 1])) # 히든 스테이트 계산
        ys[i] = np.dot(V, hs[i]) # 출력 벡터 계산
        ps[i] = np.exp(ys[i]) / np.sum(np.exp(ys[i]))  # softmax 계산
        loss += -np.log(ps[i][targets[i], 0]) # Cross-Entropy 계산해서 누적 손실 측정
    return loss, ps, hs, xs
</pre>

설명:

입력 데이터를 받아 모델의 예측을 생성하고, 실제 정답과의 오차(손실, loss)를 계산하는 과정입니다.

1. 입력 단어를 원-핫 인코딩 벡터(`xs`)로 변환합니다.

2. RNN의 핵심 계산(입력 + 이전 은닉 상태)을 통해 현재 시점의 은닉 상태(`hs`)를 계산합니다. (활성화 함수는 tanh 사용)

3. 은닉 상태를 이용해 어휘집의 모든 단어에 대한 점수(logit, `ys`)를 계산합니다.

4. Softmax 함수를 통해 점수를 확률 분포(`ps`)로 변환합니다.

5. 교차 엔트로피(Cross-Entropy) 손실 함수를 사용하여 모델의 예측이 얼마나 틀렸는지(`loss`)를 측정합니다.

역전파에 필요한 중간 계산 값들(ps, hs, xs)을 함께 반환합니다.


--------------------------------------------------
5. 역전파 함수 (BPTT)
--------------------------------------------------
<pre>
def backward(ps, hs, xs):
    # 처음에 모든 가중치들은 0으로 설정
    dV = np.zeros(V.shape)
    dW = np.zeros(W.shape)
    dU = np.zeros(U.shape)

    for i in range(seq_len)[::-1]:
        output = np.zeros((vocab_size, 1))
        output[targets[i]] = 1
        ps[i] = ps[i] - output.reshape(-1, 1)
        # 매번 i스텝에서 dL/dVi를 구하기
        dV_step_i = ps[i] @ (hs[i]).T  # (y_hat - y) @ hs.T - for each step

        dV = dV + dV_step_i  # dL/dVi를 다 더하기

        # 각i별로 V와 W를 구하기 위해서는
        # 먼저 공통적으로 계산되는 부분을 delta로 해서 계산해두고
        # 그리고 시간을 거슬러 dL/dWij와 dL/dUij를 구한 뒤
        # 각각을 합하여 dL/dW와 dL/dU를 구하고
        # 다시 공통적으로 계산되는 delta를 업데이트

        # i번째 스텝에서 공통적으로 사용될 delta
        delta_recent = (V.T @ ps[i]) * (1 - hs[i] ** 2)

        # 시간을 거슬러 올라가서 dL/dW와 dL/dU를 구하기
        for j in range(i + 1)[::-1]:
            dW_ij = delta_recent @ hs[j - 1].T

            dW = dW + dW_ij

            dU_ij = delta_recent @ xs[j].reshape(1, -1)
            dU = dU + dU_ij

            # 그리고 다음번 j번째 타임에서 공통적으로 계산할 delta를 업데이트
            delta_recent = (W.T @ delta_recent) * (1 - hs[j - 1] ** 2)

        for d in [dU, dW, dV]:
            np.clip(d, -1, 1, out=d)
    return dU, dW, dV, hs[len(inputs) - 1]
</pre>

설명:

*** 경고: 이 함수의 BPTT 구현에는 논리적 오류가 있습니다. ***

순전파에서 계산된 손실을 기반으로, 각 가중치가 오차에 얼마나 기여했는지를 나타내는 경사(gradient)를 계산합니다.

- 의도: 시간의 역순으로 오차를 전파하며(BPTT), 각 가중치 행렬(U, W, V)에 대한 미분값(dU, dW, dV)을 계산합니다.

- 문제점: 중첩된 `for` 루프(`for i`, `for j`)는 BPTT의 올바른 구현이 아닙니다. 이로 인해 앞선 시점의 그래디언트가 불필요하게 중복 계산되어 학습을 방해합니다.

- Gradient Clipping: `np.clip`은 그래디언트 값이 비정상적으로 커지는 'exploding gradients' 문제를 방지하는 중요한 기법입니다.

def predict(word, length):
    x = np.zeros((vocab_size, 1))
    x[word_to_ix[word]] = 1 # 시작 단어를 one-hot encoding
    ixes = [] # 예측된 단어 인덱스 리스트
    h = np.zeros((h_size,1)) # 초기 hidden state

    for t in range(length):
        h = np.tanh(np.dot(U, x) + np.dot(W, h))
        y = np.dot(V, h)
        p = np.exp(y) / np.sum(np.exp(y)) # 소프트맥스
        ix = np.argmax(p) # 가장 높은 확률의 index를 리턴
        x = np.zeros((vocab_size, 1)) # 다음번 input x를 준비
        x[ix] = 1
        ixes.append(ix)

    # 예측된 인덱스 리스트 ixes를 실제 단어로 변환
    # 공백으로 이어 붙여 하나의 문장처럼 반환
    pred_words = ' '.join(ix_to_word[i] for i in ixes)
    return pred_words
</pre>

설명:

학습된 가중치를 사용하여 새로운 텍스트를 생성합니다.

1. 시작 단어를 입력받아 원-핫 벡터로 변환합니다.

2. 순전파와 동일한 방식으로 다음 단어의 확률 분포를 계산합니다.

3. `np.argmax`를 사용하여 확률이 '가장 높은' 단어를 다음 단어로 선택합니다 (Greedy Search 방식).

4. 선택된 단어를 다시 다음 스텝의 입력으로 사용하여 지정된 길이(`length`)만큼 이 과정을 반복합니다.

5. 생성된 단어 인덱스들을 실제 단어로 변환하여 하나의 문장으로 반환합니다.

7. 하이퍼파라미터 설정 및 학습/예측 실행
--------------------------------------------------
<pre>
# 기본적인 parameters
epochs = 10000
h_size = 100
seq_len = 3
learning_rate = 1e-2

tokens, vocab_size, word_to_ix, ix_to_word = data_preprocessing(data)
U, W, V = init_weights(h_size, vocab_size)

# 학습 루프
p = 0
hprev = np.zeros((h_size, 1))
for epoch in range(epochs):

    for p in range(len(tokens)-seq_len):
        inputs = [word_to_ix[tok] for tok in tokens[p:p + seq_len]] # 문장의 단어 리스트
        targets = [word_to_ix[tok] for tok in tokens[p + 1:p + seq_len + 1]] # input에 대응하는 다음 단어

        loss, ps, hs, xs = feedforward(inputs, targets, hprev) # 순전파

        dU, dW, dV, hprev = backward(ps, hs, xs) # 역전파

        # 경사하강법으로 가중치 업데이트
        W -= learning_rate * dW
        U -= learning_rate * dU
        V -= learning_rate * dV

        # p += seq_len

    if epoch % 100 == 0:
        print(f'epoch {epoch}, loss: {loss}')

# 사용자에게 입력 받아 다음 단어 예측
while 1:
    try:
        user_input = input("input: ")
        if user_input == 'break':
            break
        response = predict(user_input,40)
        print(response)
    except:
        print('Uh oh try again!')
</pre>

설명:

- 하이퍼파라미터: 모델의 학습 방식을 결정하는 주요 설정값들입니다. (에포크 수, 은닉 상태 크기, 시퀀스 길이, 학습률)

- 초기화: 데이터 전처리 및 가중치 초기화 함수를 호출하여 학습 준비를 합니다.

- 학습 루프:
  1. 전체 데이터를 `epochs` 횟수만큼 반복 학습합니다.
  2. 텍스트를 `seq_len` 길이만큼 잘라가며 `inputs`와 `targets`를 만듭니다.
  3. `feedforward`와 `backward`를 순차적으로 호출하여 손실과 그래디언트를 계산합니다.
  4. 계산된 그래디언트와 학습률을 사용하여 가중치(U, W, V)를 업데이트합니다 (경사 하강법).
  5. 100 에포크마다 손실 값을 출력하여 학습 진행 상황을 모니터링합니다.

- 예측 루프: 학습이 끝난 후, 사용자 입력을 받아 `predict` 함수를 호출하여 결과를 출력하는 무한 루프를 실행합니다.


[ 3. 종합 결론 ]

이 코드는 RNN의 기본 구조와 순전파 과정을 이해하는 데 매우 훌륭한 교육 자료입니다.

하지만 `backward` 함수에 구현된 BPTT 로직의 치명적인 오류로 인해 모델이 효과적으로 학습하기는 어렵습니다.

이 버그를 올바른 BPTT 로직으로 수정한다면, 'from-scratch' RNN을 구현해보는 완벽한 교육용 예제가 될 것입니다.
