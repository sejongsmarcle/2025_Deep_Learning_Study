<pre>
class CNN(torch.nn.Module):
    def __init__(self):
        super(CNN, self).__init__()
        self.layer1 = torch.nn.Sequential(
            torch.nn.Conv2d(1, 16, kernel_size=5, stride=1, padding=2),
            torch.nn.ReLU(),
            torch.nn.MaxPool2d(kernel_size=2, stride=2))
        self.layer2 = torch.nn.Sequential(
            torch.nn.Conv2d(16, 32, kernel_size=5, stride=1, padding=2),
            torch.nn.ReLU(),
            torch.nn.MaxPool2d(kernel_size=2, stride=2))
        self.fc = torch.nn.Linear(32 * 7 * 7, 10, bias=True)
        torch.nn.init.xavier_uniform_(self.fc.weight)
    def forward(self, x):
        out = self.layer1(x)
        out = self.layer2(out)
        out = out.view(out.size(0), -1)   
        out = self.fc(out)
        return out
</pre>

- __init__: 모델에 필요한 계층(layer)들을 정의하는 생성자입니다.
  
- Conv2d(1, 16, ...): 흑백 이미지(채널 1)를 입력받아 16개의 특징 맵(feature map)을 출력하는 2D 합성곱 계층입니다.

- padding=2를 주어 입력과 출력의 크기가 같게 유지됩니다 (28x28 -> 28x28).
  
- ReLU(): 활성화 함수로, 비선형성을 추가합니다.

- MaxPool2d(...): 이미지의 크기를 절반으로 줄여(28x28 -> 14x14) 계산량을 줄이고 주요 특징을 추출합니다.

- layer2: layer1에서 나온 16개 특징 맵을 입력받아 32개의 특징 맵을 만들고, 다시 한 번 풀링을 통해 크기를 절반으로 줄입니다 (14x14 -> 7x7).
  
- fc (Fully Connected): 마지막 합성곱 계층을 통과한 32개의 7x7 특징 맵을 일렬로 펼쳐서 입력으로 받습니다
  
- torch.nn.init.xavier_uniform_: 가중치를 효과적으로 초기화하여 학습이 더 안정적으로 이루어지도록 돕습니다.
  
- forward: 데이터가 모델의 각 계층을 통과하는 순서를 정의합니다.
  
- out.view(out.size(0), -1): 2D 형태의 특징 맵을 1D 벡터로 펼쳐서 Fully Connected 계층에 입력할 수 있도록 변환하는 부분입니다.

- CrossEntropyLoss: 다중 클래스 분류 문제에서 널리 사용되는 손실 함수(loss function)입니다. 모델의 예측이 실제 정답과 얼마나 다른지를 측정합니다.

- Adam Optimizer: 경사 하강법을 통해 손실을 최소화하는 방향으로 모델의 가중치를 업데이트하는 역할을 합니다. Adam은 가장 대중적이고 성능이 좋은 옵티마이저 중 하나입니다.

- learning_rate: 옵티마이저가 가중치를 얼마나 큰 폭으로 업데이트할지 결정하는 하이퍼파라미터입니다.

<pre>
total_batch = len(loaders['train'])
for epoch in range(training_epochs):
    avg_cost = 0
    for X, Y in loaders['train']:
        optimizer.zero_grad()
        pred = model(X)
        cost = loss_func(pred, Y)
        cost.backward()
        optimizer.step()
        avg_cost += cost / total_batch
    print('[Epoch: {:>4}] cost = {:>.9}'.format(epoch + 1, avg_cost))

print('Learning Finished!')
</pre>

- 바깥쪽 for 루프는 전체 데이터셋을 10번 반복 학습(training_epochs=10)합니다.

- 안쪽 for 루프는 DataLoader에서 배치 단위로 데이터를 가져옵니다.

- 학습 단계:

- optimizer.zero_grad(): 이전 배치의 기울기(gradient) 값을 초기화합니다.

- pred = model(X): 모델에 데이터를 입력하여 예측값을 얻습니다 (순전파, Forward Pass).

- cost = loss_func(pred, Y): 예측값과 실제 정답(Y)을 비교하여 손실을 계산합니다.

- cost.backward(): 손실을 기반으로 각 가중치의 기울기를 계산합니다 (역전파, Backward Pass).

- optimizer.step(): 계산된 기울기를 사용하여 모델의 가중치를 업데이트합니다.

- 매 에폭이 끝날 때마다 평균 손실(cost)을 출력하여 학습이 잘 진행되고 있는지 확인합니다. 손실 값이 점차 줄어드는 것을 볼 수 있습니다.
