국민 청원 분류하기

1. 프로젝트 소개
   
목표: 국민 청원 데이터(제목, 내용)를 분석하여, 실제 참여 인원은 적더라도 향후 1,000명 이상의 참여를 이끌어낼 가능성이 있는 청원을 예측하고 분류합니다.


데이터: 청와대 국민청원 사이트에서 특정 기간(청원 번호 584,274 ~ 595,226)의 데이터를 웹 크롤링하여 수집합니다.

핵심 기술:

웹 크롤링: requests, BeautifulSoup를 사용하여 웹 페이지의 텍스트 데이터를 수집합니다.

자연어 처리(NLP): KoNLPy를 이용해 한국어 텍스트를 형태소 및 명사 단위로 토크나이징하고, re 모듈로 불필요한 문자를 제거합니다.

단어 임베딩: Gensim의 Word2Vec 모델을 사용하여 토큰화된 단어들을 밀집 벡터(dense vector)로 변환합니다.

딥러닝 모델: PyTorch를 기반으로 TextCNN 모델을 구축하여 텍스트를 분류합니다.

2. 데이터 수집 및 전처리

2.1. 웹 크롤링 (Web Crawling)

requests와 BeautifulSoup 라이브러리를 사용하여 국민청원 웹사이트에서 각 청원별 제목, 참여 인원, 카테고리, 내용 등의 데이터를 수집합니다. 서버에 과도한 부하를 주지 않기 위해 일정 개수의 데이터를 수집한 
후 time.sleep()을 통해 잠시 대기합니다.

<pre>
import pandas as pd
import numpy as np
import requests
from bs4 import BeautifulSoup
import time

# 크롤링 결과를 저장할 빈 데이터프레임을 생성합니다.
result = pd.DataFrame()

# 지정된 범위의 청원 번호를 순회하며 데이터를 수집합니다.
for i in range(584274, 595226):
URL = "http://www1.president.go.kr/petitions/" + str(i)
response = requests.get(URL)
html = response.text
soup = BeautifulSoup(html, 'html.parser')

# HTML 태그와 클래스명을 기반으로 원하는 정보를 추출합니다.
title = soup.find('h3', class_='petitionsView_title')
count = soup.find('span', class_='counter')
content = soup.select_one('div.petitionsView_write > div.View_write')

# 카테고리, 시작일, 마감일 정보 추출
info_list = []
for tag in soup.select('ul.petitionsView_info_list > li'):
info_list.append(tag.contents[1])

# 청원 정보가 정상적으로 수집되었을 경우에만 데이터프레임에 추가합니다.
if len(info_list) != 0 and title and count and content:
df1 = pd.DataFrame({
'category': [info_list[0]],
'start': [info_list[1]],
'end': [info_list[2]],
'count': [count.text],
'title': [title.text],
'content': [content.text.strip()[:13000]]
})
result = pd.concat([result, df1], ignore_index=True)

# 60건마다 90초 대기
if i % 60 == 0:
print(f"Sleep 90seconds. Count: {i}, Data Length: {len(result)}")
time.sleep(90)

print("크롤링 완료. 최종 데이터 shape:", result.shape)
df = result.copy()
</pre>

2.2. 텍스트 정제 및 피처 생성

수집된 텍스트 데이터에는 불필요한 공백, 특수문자 등이 포함되어 있습니다. 정규표현식(re)을 사용하여 이러한 문자들을 제거하여 데이터를 정제합니다. 또한, 모델 학습에 사용할 피처(Feature)와 레이블(Label)을 생성합니다.

<pre>
import re

# 텍스트 정제를 위한 함수를 정의합니다.
def remove_white_space(text):
text = re.sub(r'[\t\r\n\f\v]', ' ', str(text))
return text

def remove_special_char(text):
text = re.sub('[^ ㄱ-ㅣ가-힣 0-9]+', ' ', str(text))
return text

# 청원 제목과 내용에 정제 함수를 적용합니다.
df['title'] = df['title'].apply(remove_white_space).apply(remove_special_char)
df['content'] = df['content'].apply(remove_white_space).apply(remove_special_char)

# 참여 인원(count) 컬럼을 숫자(int) 형식으로 변환합니다.
df['count'] = df['count'].str.replace(',', '').astype(int)

# 참여 인원 1,000명을 기준으로 'Yes'/'No' 레이블을 생성합니다.
df['label'] = df['count'].apply(lambda x: 'Yes' if x >= 1000 else 'No')
</pre>
3. 토크나이징 및 단어 임베딩

모델이 텍스트를 이해할 수 있도록, 문장을 의미있는 최소 단위인 토큰(Token)으로 분리하는 토크나이징 과정을 거칩니다. 이후, 각 토큰을 고차원의 숫자 벡터로 변환하는 단어 임베딩을 수행합니다.

3.1. 토크나이징 (Tokenizing)

KoNLPy의 Okt 형태소 분석기를 사용하여 제목은 형태소 단위로, 내용은 명사 단위로 토큰을 추출합니다. 두 결과를 합쳐 최종 분석에 사용할 토큰 리스트를 만듭니다.
<pre>
from konlpy.tag import Okt

okt = Okt()

# 제목은 형태소, 내용은 명사 단위로 토큰화합니다.
df['title_token'] = df.title.apply(okt.morphs)
df['content_token'] = df.content.apply(okt.nouns)

# 제목과 내용 토큰을 합쳐 최종 토큰 리스트를 생성합니다.
df['token_final'] = df.title_token + df.content_token

# 분석에 필요한 컬럼만 남깁니다.
df_drop = df[['token_final', 'label']]
</pre>
3.2. 단어 임베딩 (Word Embedding with Word2Vec)
Gensim 라이브러리의 Word2Vec 모델을 사용하여 토큰화된 단어들을 100차원의 벡터로 변환합니다. 이 과정을 통해 단어의 의미와 문맥적 관계가 벡터 공간에 표현됩니다.
<pre>
from gensim.models import Word2Vec
from gensim.models import KeyedVectors

# Word2Vec 모델을 학습합니다.
embedding_model = Word2Vec(df_drop['token_final'],
sg=1, # Skip-gram 방식 사용
vector_size=100, # 임베딩 벡터 차원
window=2, # 주변 단어 수
min_count=1, # 최소 단어 빈도
workers=4)

# 학습된 임베딩 모델을 저장하고 다시 로드하여 정상적으로 작동하는지 확인합니다.
embedding_model.wv.save_word2vec_format('data/petitions_tokens_w2v')
loaded_model = KeyedVectors.load_word2vec_format('data/petitions_tokens_w2v')

# '음주운전'과 가장 유사한 단어를 출력해봅니다.
model_result = loaded_model.most_similar("음주운전")
print(model_result)
</pre>

4. 데이터셋 구축

학습을 위해 전체 데이터를 훈련(Train) 데이터와 검증(Validation) 데이터로 8:2 비율로 분할합니다. 그 후 torchtext를 사용하여 모델에 입력할 수 있는 형태의 데이터셋과 데이터로더를 만듭니다.
<pre>
import torch
import torchtext
from torchtext.data import Field, TabularDataset, BucketIterator
from torchtext.vocab import Vectors
from numpy.random import RandomState
import re

# 1. 데이터 분할 및 저장
rng = RandomState()
train_data = df_drop.sample(frac=0.8, random_state=rng)
val_data = df_drop.loc[~df_drop.index.isin(train_data.index)]

train_data.to_csv('data/train.csv', index=False, encoding='utf-8-sig')
val_data.to_csv('data/validation.csv', index=False, encoding='utf-8-sig')

# 2. Field 정의
def tokenizer(text):
text = re.sub('[\[\]\']', '', str(text))
text = text.split(', ')
return text

TEXT = Field(tokenize=tokenizer)
LABEL = Field(sequential=False)

# 3. 데이터셋 생성
train, validation = TabularDataset.splits(
path='data/',
train='train.csv',
validation='validation.csv',
format='csv',
fields=[('text', TEXT), ('label', LABEL)],
skip_header=True
)

# 4. 단어장(Vocabulary) 및 데이터로더(DataLoader) 생성
vectors = Vectors(name="data/petitions_tokens_w2v")
TEXT.build_vocab(train, vectors=vectors, min_freq=1, max_size=None)
LABEL.build_vocab(train)

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

train_iter, validation_iter = BucketIterator.splits(
datasets=(train, validation),
batch_size=8,
device=device,
sort=False
)
</pre>

5. 모델링 (TextCNN)

텍스트 분류에 효과적인 TextCNN(Convolutional Neural Network for Text) 모델을 정의합니다. 이 모델은 임베딩 레이어, 여러 크기의 커널을 가진 컨볼루션 레이어, 맥스 풀링 레이어, 그리고 최종 분류를 위한 완전 연결 레이어로 구성됩니다.
<pre>
import torch.nn as nn
import torch.nn.functional as F

class TextCNN(nn.Module):
def __init__(self, vocab_built, emb_dim, dim_channel, kernel_wins, num_class):
super(TextCNN, self).__init__()

self.embed = nn.Embedding(len(vocab_built), emb_dim)
self.embed.weight.data.copy_(vocab_built.vectors)

self.convs = nn.ModuleList([nn.Conv2d(1, dim_channel, (w, emb_dim)) for w in kernel_wins])
self.dropout = nn.Dropout(0.4)

self.fc = nn.Linear(len(kernel_wins) * dim_channel, num_class)

def forward(self, x):
emb_x = self.embed(x)
emb_x = emb_x.unsqueeze(1)

con_x = [F.relu(conv(emb_x)) for conv in self.convs]

pool_x = [F.max_pool1d(x.squeeze(-1), x.size()[2]).squeeze(2) for x in con_x]

fc_x = torch.cat(pool_x, dim=1)

fc_x = self.dropout(fc_x)
logit = self.fc(fc_x)
return logit
</pre>
6. 학습 및 평가
정의된 모델, 데이터로더, 손실 함수, 옵티마이저를 사용하여 모델을 학습시키고 성능을 평가합니다. 검증 데이터셋에서 가장 높은 정확도를 보인 모델의 가중치를 저장합니다.
<pre>
import torch.optim as optim

# 학습 함수
def train(model, device, train_itr, optimizer):
model.train()
corrects, train_loss = 0.0, 0
for batch in train_itr:
text, target = batch.text.transpose(0, 1), batch.label
target.data.sub_(1)
text, target = text.to(device), target.to(device)

optimizer.zero_grad()
logit = model(text)
loss = F.cross_entropy(logit, target)
loss.backward()
optimizer.step()

train_loss += loss.item()
result = torch.max(logit, 1)[1]
corrects += (result == target).sum().item()

train_loss /= len(train_itr.dataset)
accuracy = 100.0 * corrects / len(train_itr.dataset)
return train_loss, accuracy

# 평가 함수
def evaluate(model, device, itr):
model.eval()
corrects, test_loss = 0.0, 0
with torch.no_grad():
for batch in itr:
text, target = batch.text.transpose(0, 1), batch.label
target.data.sub_(1)
text, target = text.to(device), target.to(device)

logit = model(text)
loss = F.cross_entropy(logit, target)

test_loss += loss.item()
result = torch.max(logit, 1)[1]
corrects += (result == target).sum().item()

test_loss /= len(itr.dataset)
accuracy = 100.0 * corrects / len(itr.dataset)
return test_loss, accuracy

# 모델 인스턴스화 및 학습 진행
model = TextCNN(TEXT.vocab, 100, 10, [3, 4, 5], 2).to(device)
optimizer = optim.Adam(model.parameters(), lr=0.001)

best_val_acc = -1.0
EPOCHS = 3

for epoch in range(1, EPOCHS + 1):
tr_loss, tr_acc = train(model, device, train_iter, optimizer)
print(f'Train Epoch: {epoch} \t Loss: {tr_loss:.4f} \t Accuracy: {tr_acc:.2f}%')

val_loss, val_acc = evaluate(model, device, validation_iter)
print(f'Valid Epoch: {epoch} \t Loss: {val_loss:.4f} \t Accuracy: {val_acc:.2f}%')

if val_acc > best_val_acc:
best_val_acc = val_acc
print(f"Model saved at {best_val_acc:.2f}% accuracy")
torch.save(model.state_dict(), "TextCNN_Best_Validation.pt")

print('-----------------------------------------------------------------------------')
</pre>
